# 🌌 NovaChat

![NovaChat Banner](https://via.placeholder.com/1200x400/05050f/6366f1?text=NovaChat+-+Futuristic+Real-time+Messaging)

NovaChat is a premium, futuristic real-time chat application built with Next.js 14, Supabase, and Tailwind CSS. It features a custom Email OTP authentication system, real-time messaging, presence tracking, and a stunning glassmorphism UI powered by Framer Motion.

## ✨ Features

- **🚀 Real-time Messaging:** Lightning-fast message delivery powered by Supabase Realtime.
- **🔐 Custom Email OTP Verification:** Secure and custom email authentication using the **Resend API**.
- **🟢 Live Presence Tracking:** Instantly see when users come online or go offline.
- **💬 Typing Indicators & Read Receipts:** Real-time feedback when a partner is typing, plus unread message badges.
- **🔍 Global User Search:** Find and connect with anyone instantly using their unique username.
- **🎨 Premium UI/UX:** Futuristic "Aurora" glassmorphism design with smooth micro-animations using Framer Motion.
- **🛡️ Secure by Design:** Enforced Row Level Security (RLS) and custom database RPC functions.

## 🛠️ Tech Stack

- **Frontend:** Next.js 14 (App Router), React, Tailwind CSS
- **Animations:** Framer Motion, Lucide React (Icons)
- **Backend & Database:** Supabase (PostgreSQL, Realtime, Auth)
- **Email Service:** Resend SDK
- **Deployment:** Vercel

## ⚙️ Prerequisites

Before you begin, ensure you have the following accounts and keys ready:
- Node.js (v18+)
- A [Supabase](https://supabase.com/) Project
- A [Resend](https://resend.com/) Account & API Key
